Day 2 – Bag of Words (Text Vectorization)
Overview

This mini project focuses on converting text data into numerical format using the Bag of Words (BoW) technique.
Since machine learning models cannot understand raw text, vectorization is a crucial step in every NLP pipeline.

What is Bag of Words?

Bag of Words is a text representation technique that:

Creates a vocabulary from all unique words in the dataset

Represents each document as a vector of word counts

Ignores word order and grammar

 Steps Performed

Collected sample text documents

Created a vocabulary from all documents

Counted word occurrences in each document

Converted text into a numerical matrix (Document–Term Matrix)
